# 🐍 Snake Game

Un jeu **Snake** développé avec **React.js** et **Vite**.

Le joueur contrôle le serpent à l'aide du clavier, récupère les aliments pour augmenter son score et doit éviter les collisions.

## 🌐 Démo en ligne

👉 https://snake-game-six-gilt.vercel.app/

> 💻 **Compatible PC uniquement** — Le jeu utilise les touches du clavier pour contrôler le serpent et n'est actuellement pas adapté aux téléphones.

## ✨ Fonctionnalités

* 🐍 Contrôle du serpent avec le clavier
* 🍎 Système de nourriture
* 📊 Calcul du score
* 💥 Détection des collisions
* 🔄 Recommencer la partie
* 🎮 Gameplay interactif

## 🛠️ Technologies utilisées

* **React.js**
* **Vite**
* **JavaScript**
* **HTML5**
* **CSS3**

## 🚀 Installation

### 1. Cloner le repository

```bash
git clone https://github.com/IkramCodes1/snake-game.git
```

### 2. Accéder au projet

```bash
cd snake-game
```

### 3. Installer les dépendances

```bash
npm install
```

### 4. Lancer le projet

```bash
npm run dev
```

Le projet sera disponible sur :

```text
http://localhost:5173
```

## 📦 Build

```bash
npm run build
```
